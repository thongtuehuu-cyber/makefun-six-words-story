A make.fun bounty entry: one complete story told in exactly six words.

**The story:**

> The letter arrived after the funeral.

A letter sent, a death, a message that arrives too late — a whole life and a missed connection implied in six words, with the turn landing on the final word.

## Run it

```sh
python3 main.py
cat /output/entry.txt   # "The letter arrived after the funeral."
```

`main.py` (Python 3.13) simply writes the story to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set, for local testing). It is deterministic: no network, no randomness, no external files. The text is exactly 6 words and 37 characters (plus a trailing newline), well within the 1–60 character gate, valid UTF-8.
